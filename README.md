**Cornet et al.** (2026) From shape to source: Sedimentary charcoal morphology as a proxy for tropical burned biomass composition. Journal of Quaternary Science, 1–17. [https://doi.org/10.1002/jqs.70053](https://onlinelibrary.wiley.com/doi/10.1002/jqs.70053)
